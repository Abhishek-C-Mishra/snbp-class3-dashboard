# My School Dashboard

A simple GitHub Pages school organizer for homework, exams, notices, activities and timetables.

## Features
- Automatic next-10-days view
- Homework, exams, notices and activities
- Priority and action-required flags
- Today's timetable
- Weekly timetable editor
- Add/edit/delete items
- JSON export/import backup
- Mobile responsive
- Browser localStorage (no backend required)

## GitHub Pages
Create a repository, upload `index.html`, `style.css`, and `app.js`, then go to:

Settings → Pages → Build and deployment → Source → Deploy from a branch → `main` / `/root`.

GitHub Pages publishes static HTML/CSS/JavaScript files.
